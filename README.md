# 📚 FocoConcurso — Cronômetro de Estudos para Concursos

Aplicação web desenvolvida para auxiliar estudantes e concurseiros no gerenciamento do tempo de estudo, permitindo registrar sessões, acompanhar horas estudadas e manter um histórico de produtividade.

O **FocoConcurso** foi criado com o objetivo de incentivar a disciplina, a organização e a constância na preparação para concursos públicos.

## 🚀 Funcionalidades

- ⏱️ **Cronômetro de Estudos:** controle do tempo dedicado a cada sessão.
- ▶️ **Iniciar, Pausar e Finalizar:** gerenciamento simples das sessões de estudo.
- 📖 **Identificação de Matérias:** possibilidade de informar a matéria ou o tópico estudado.
- 📊 **Estatísticas Diárias:** acompanhamento do tempo total estudado no dia.
- 📝 **Histórico de Estudos:** registro das sessões realizadas.
- 🗑️ **Gerenciamento de Histórico:** exclusão individual ou limpeza de todos os registros.
- 💾 **Armazenamento Local:** os dados ficam salvos no navegador por meio do LocalStorage.
- 📱 **Layout Responsivo:** interface adaptável para computadores, tablets e smartphones.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias voltadas para aplicações web:

- **HTML5:** estruturação da aplicação.
- **Tailwind CSS:** estilização e responsividade da interface.
- **JavaScript:** implementação das funcionalidades e regras do cronômetro.
- **LocalStorage:** armazenamento local das sessões de estudo.
- **Font Awesome:** ícones utilizados na interface.

## 🎨 Interface

A aplicação apresenta uma interface moderna, com tema escuro e elementos visuais que facilitam o acompanhamento das atividades.

### Principais recursos da interface

- Painel de cronômetro.
- Campo para identificação da matéria.
- Botões de controle das sessões.
- Indicadores de produtividade.
- Tabela com histórico de estudos.

## 💻 Como executar o projeto

Não é necessário instalar servidores ou configurar banco de dados.

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador de sua preferência.

Também é possível executar utilizando a extensão **Live Server** no Visual Studio Code.

## 💾 Armazenamento de Dados

O projeto utiliza o recurso `LocalStorage` do navegador para armazenar o histórico das sessões de estudo.

Isso significa que:

- Os registros permanecem salvos após fechar o navegador.
- Não é necessário utilizar banco de dados.
- Os dados ficam armazenados localmente no dispositivo e navegador utilizados.
- A limpeza dos dados do navegador pode remover os registros salvos.
